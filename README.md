# Task Manager

A simple Task Manager web application built with Python Flask and SQLite.

## Features

- Add tasks
- View tasks
- Edit tasks
- Mark tasks as completed
- Delete tasks
- Store tasks in SQLite database

## Technologies Used

- Python
- Flask
- SQLite
- HTML
- CSS
- JavaScript

## How to Run

1. Install Python.
2. Install Flask:
   `pip install flask`
3. Open the project folder in VS Code.
4. Run:
   `python app.py`
5. Open:
   `http://127.0.0.1:5000/app`

## Project Structure

- `app.py` — Flask backend
- `index.html` — Frontend
- `test_api.py` — API testing
- `tasks.db` — SQLite database
